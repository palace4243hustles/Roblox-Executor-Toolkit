## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox executor tools bundled with a universal loader for Windows. It includes Volt, Synapse Z, Potassium, and Wave, all managed through a single convenient interface.

### Is XCutors free to use?

Yes, the XCutors loader and package distribution are free. However, some individual executors included in the bundle may have their own licensing, premium tiers, or separate requirements set by their original developers.

### What are the system requirements?

XCutors requires a Windows 10 or Windows 11 (64-bit) operating system, at least 4 GB of RAM, .NET Framework 4.8 or later, and an active internet connection for updates and script library access.

### How do I update the executors?

The universal loader (xcutorsLoader) includes a built-in update checker. When a new version of any included executor is available, you will receive a notification prompt to download and install the update automatically.

### Can I add my own scripts to the library?

Yes. You can add custom scripts by placing .lua or .txt script files into the 'Scripts' folder within the XCutors directory. They will automatically appear in the built-in script library browser.

### Which executor should I choose?

Each executor has different strengths. Volt is known for speed and stability, Synapse Z for broad script compatibility, Potassium for its lightweight footprint, and Wave for its modern UI. You can switch between them freely using the universal loader.

### My anticomponent flagged the application. Is it safe?

Some anticomponent programs may flag script executors due to their injection behavior, which can resemble suspicious activity. Always download XCutors only from the official GitHub repository. You may need to whitelist the application in your anticomponent settings.

### Does XCutors work on Roblox UWP (Microsoft Store) versions?

Executor compatibility depends on each individual tool. Refer to the documentation of each specific executor within the package for details on UWP and standard Roblox client support.

### Where can I report bugs or request features?

You can report bugs or request new features by opening an Issue on the official XCutors GitHub repository. Please use the provided templates and include as much detail as possible for faster resolution.

### Is multi-instance (running multiple Roblox clients) supported?

Multi-instance support depends on the specific executor you are using. The universal loader can manage multiple attached sessions if the underlying executor supports it. Check each executor's documentation for details.
